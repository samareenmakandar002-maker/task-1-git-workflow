# Git Branching Notes

## Main Branch

The `main` branch contains the stable version of the application.

## Feature Branch

The `feature/sample-app` branch was created to develop the Task Manager sample application without directly modifying the main branch.

## Workflow

1. Create a feature branch from `main`.
2. Develop and test the application on the feature branch.
3. Commit changes with meaningful commit messages.
4. Merge the completed feature branch into `main`.
5. Push the updated `main` branch to GitHub.

## Branch Structure

- `main` - Stable production-ready code
- `feature/sample-app` - Development of the Task Manager application

## Commit Practice

Each commit should represent a meaningful change and use a clear commit message.
