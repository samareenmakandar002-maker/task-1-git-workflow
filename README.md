# Task 1 - Git Workflow

A simple Task Manager web application demonstrating a clean Git workflow with branching, commits, and version control.

## Project Overview

This project was created as a sample application to demonstrate how Git can be used effectively during software development.

The application allows users to:

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Manage tasks through a simple and clean interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code
